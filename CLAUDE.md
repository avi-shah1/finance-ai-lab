# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

# Project goal

I am learning how to build AI-enabled web applications and internal workflow tools.

# How to work with me

Before making a significant change:
1. Explain what you are about to do in plain English.
2. Tell me which files you will change.
3. Explain the important parts of the diff.
4. If something breaks, explain the root cause before attempting multiple fixes.

# Teaching preference

Assume I am a beginner developer.
Explain architecture, APIs, databases, environment variables and errors when they appear.
Do not hide complexity unnecessarily.
